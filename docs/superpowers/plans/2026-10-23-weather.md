# Weather Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Byte answers about the weather (home = Goiânia, or any city), and the panel shows it — a bar chip plus a "05 Tempo" section — switching city instantly when the owner asks Byte to *show* another one.

**Architecture:** New `WeatherPort` (Open-Meteo adapter + in-memory adapter), an application `WeatherDisplay` holding which place the panel shows and notifying one listener, two tools (`get_weather`, `show_weather`, segment `weather`), `GET /weather` + `DELETE /weather/display`, and a server→panel push socket `WS /ws/panel`. The panel renders layout A with SVG art in the house style.

**Tech Stack:** Python 3.12, FastAPI, aiohttp (already locked), pytest; vanilla JS + `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-23-weather-design.md` — read it first; this plan does not repeat its "why".

## Global Constraints

- `CLAUDE.md` hard rules: `domain/` stdlib only (`@dataclass(frozen=True, slots=True)`), ports `ABC` + `@abstractmethod`, `pyright --strict`, no `print()`, errors subclass `DomainError` and keep `__cause__`, singletons only via `lru_cache` in `api/deps.py`.
- Never log tool arguments (the city), transcripts or content.
- No new runtime package: `aiohttp` comes through a new `weather` extra; `requirements.lock` already pins it.
- Open-Meteo endpoints and query params exactly as in the spec's **Data source** section; `forecast_days=7`, `timezone=auto`.
- Cache: forecast 600 s per place (injected monotonic clock), places for the process lifetime.
- Home: `BYTE_WEATHER_HOME`, default `"Goiânia, GO"`.
- Panel token only as the `["bearer", <token>]` WebSocket subprotocol, never in a URL.
- `show_weather` is not `panel_only` and not `requires_confirmation`; neither is `get_weather`.
- Copy is pt-BR; code, comments, commits in English. Conventional Commits.
- Gate before each commit: `ruff check . && ruff format . && pyright && pytest`.

## Review Focus

1. City typed without accents or in another case ("goiania", "FLORIANÓPOLIS") → resolves like the accented name. (Task 1 contract + Task 2.)
2. Open-Meteo returns `null` in `hourly.precipitation_probability` for some hours → treated as 0, never a crash. (Task 2.)
3. Forecast asked at 23:xx → `hours` still has 24 points crossing midnight, starting at the current hour. (Task 2.)
4. `show_weather` with no panel connected, or with a listener whose send raises → the tool still answers success. (Task 3.)
5. Panel socket closed with 4000 (replaced) or 1008 (bad token) → no reconnect loop; any other close → reconnect with backoff, and reload `/weather` on reopen. (Task 6.)

### Task 3: `WeatherDisplay`

**Interfaces:**
- Consumes: `WeatherPort`, `Place`.
- Produces:

```python
class WeatherListener(ABC):
    @abstractmethod
    async def changed(self) -> None: """What the panel shows changed. Must not raise."""

class WeatherDisplay:
    def __init__(self, weather: WeatherPort, home_query: str) -> None
    async def home(self) -> Place            # find_place(home_query), resolved once then kept
    async def shown(self) -> Place           # the displayed place, or home
    async def show(self, place: Place | None) -> None  # None or a place equal to home → home; notifies
    def attach(self, listener: WeatherListener) -> None   # replaces any previous one
    def detach(self, listener: WeatherListener) -> None   # only if it is the current one
```

`show` notifies even when nothing changed (cheap, keeps it simple) and swallows any exception from `changed()` — a broken panel link must never fail a tool.
